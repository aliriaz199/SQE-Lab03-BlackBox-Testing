# SQE Lab 03 - Black Box Testing

## Objective
To understand Black Box Testing using Equivalence Partitioning (EP) and Boundary Value Analysis (BVA).

## Program
MarksEntryChecker.java

The program checks whether student marks are between 0 and 100 (inclusive).

## Testing Techniques
- Equivalence Partitioning (EP)
- Boundary Value Analysis (BVA)

## Test Cases
- 3 Equivalence Partitioning test cases
- 6 Boundary Value Analysis test cases
- Total: 9 test cases

## Results
All 9 test cases passed during manual testing.

- Java
- Visual Studio Code
